# Política de seguridad

## Reportar una vulnerabilidad

Si encontrás una vulnerabilidad o un comportamiento inseguro en este proyecto (en la app, en la documentación o en el protocolo):

1. **No abras un issue público** con detalles explotables.
2. Reportá de forma privada desde la pestaña **Security → Report a vulnerability** del repositorio (Private Vulnerability Reporting), o escribí directamente al mantenedor.

## Alcance

- Código de la app Android (`app/`)
- Documentación de protocolo y herramientas de captura (`docs/`)
- La política cubre este repo; el firmware del robot es de Living.AI y no se distribuye aquí.

## Compromiso

- Los reportes se tratan con prioridad y discreción.
- Se dará crédito al reportante salvo que prefiera permanecer anónimo.
